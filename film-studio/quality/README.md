# Film extraction quality baseline

This is a bounded record of inherited complexity and duplication, not a clean-code certificate. It replaces the blanket film-directory exclusions added by the shared-package extraction. New film files, companion code, CLI wrappers and shared contracts remain in analysis.

Bootstrap source: PR7 head963d9b424c1d0612a584e55db46adc2cae3fbbf9, with the blanket exclusions removed and the companion browser entry and dynamically served stylesheet explicitly registered. Nine moved service files are byte-identical to their predecessors; the inspector only adjusts its checkout-relative asset path. The recorded algorithms are not rewritten as part of extraction.

The full-fork unbaselined audit against `origin/main` reported 14 complex functions across 11 known legacy service/companion files and six film legacy clone groups. The narrower PR7-base audit reported 12 complex functions across nine service files and four clone groups. The additional two companion functions and two browser-runner groups are byte-identical to PR7; they are inherited film foundation debt, not findings introduced by this correction. Health findings include estimated test reachability/CRAP signals; these are not measured coverage percentages or newly proved functional defects. [Health counts](legacy-health-baseline.json) record only those 11 service/companion finding budgets. [Duplicate groups](legacy-dupes-baseline.json) record only six groups whose instances are all film legacy service or browser-verification paths; no unrelated upstream fingerprint is exempted.

Both CI and the local hook load the same baseline paths from `.fallowrc.jsonc` (`audit.healthBaseline` and `audit.dupesBaseline`). CI evaluates changes against the verified current PR merge first parent. The local hook retains its stricter full-fork comparison against `origin/main`; it does not infer a local PR base. Both enforce the tool's baseline-growth gate. The first reviewed addition bootstraps the files; subsequent changes compare against their base versions. Baselines must not expand to hide new findings. Count budgets are not exact per-function metric limits: a changed legacy algorithm still requires focused independent review. A removed debt item should shrink the baseline. Replacing or regenerating it is a review decision, never an automatic response to a failing audit.

The extraction quality gate uses the two centrally configured baseline files; raw unbaselined results remain useful evidence of work left to simplify. No legacy glob remains ignored. The accompanying correction retains existing behavior and makes that debt visible instead of silently dropping the directory from analysis.
